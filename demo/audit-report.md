# 暗潮之下 AI 剧情灵伴 Demo — 交互与可访问性检查

## 范围

用户在剧情暂停时识别人物，继续追问，并在侧边栏中查看对话、时间线和剧情线，最后返回播放。

## 分步结论

1. **暂停与识别 — 健康**  
   主画面仍占据视觉中心，人物聚焦与关系卡能解释“AI 看到了谁”。“无剧透”边界和“继续追问”入口明确。

2. **打开侧边栏 — 健康**  
   点击后有短暂加载反馈，侧边栏不会把用户带离视频上下文；关闭按钮清晰。

3. **对话 — 健康**  
   回答按事实确定性分层，建议问题和输入框都可操作；发送按钮缺陷已修复并复验。

4. **时间线 — 健康**  
   只展示用户已观看内容，并标出剧集与时间点；当前节点使用差异色强调。

5. **剧情线 — 健康**  
   三条线索用进度与状态表达，同时明确后续节点被隐藏，降低剧透风险。

6. **返回播放 — 健康**  
   关闭侧栏后可继续播放，并给出“已从 18:42 继续播放”的状态反馈。

## 可访问性观察

- 主要按钮、标签页、输入框均有可读名称，浏览器辅助结构可识别。
- 当前焦点状态与键盘完整遍历尚未进行专项测试；不能据此宣称符合完整 WCAG。
- 画面上的辅助文字对比度足够，但最底部体验提示属于低优先级引导，不应承载核心信息。

## 最高价值的下一步

接入真实模型与剧情数据前，优先定义“超时 / 无结果 / 内容受版权限制”的恢复路径，并用真实接口重新验收弱网与错误状态。
